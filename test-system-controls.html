System Controls Test

This is a simple test to verify the system controls functionality is working correctly.

Test Steps:

  1. Open the SettingsContentFilter component in the application
  2. Expand the "System Controls" section
  3. Test Export: Click "Export Settings" - should download a JSON file
  4. Test Import: Click "Choose File" and select a valid JSON configuration file
  5. Test Reset: Click "Reset Settings" - should show confirmation dialog
  6. Verify version information is displayed

Expected Behavior:

  • Export should create a downloadable JSON file with current settings
  • Import should show confirmation dialog before applying settings
  • Reset should show confirmation dialog before resetting to defaults
  • All operations should show success/error messages
  • Invalid file imports should show appropriate error messages
